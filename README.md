### 🚨 The Problem: Seismic Detection Limitations
Earthquakes cause massive structural damage and dangerous secondary hazards, such as fires from ruptured gas lines and victims trapped by jammed electronic locks. Traditional detection systems face technical limitations: polling-based sensors often miss rapid vibrations, fixed sensitivity thresholds ignore structural characteristics, and blocking code architectures freeze the system during critical emergency actions.

### ✅ The Solution: Proportional & Automated Response
QuakeGuard resolves these issues by utilizing a non-blocking 9-state finite state machine (FSM), interrupt-driven zero-latency detection, and dynamic threshold adjustments. By analyzing vibration frequency over a 5-second window, the system distinguishes minor tremors from dangerous earthquakes and autonomously executes emergency protocols to ensure safe evacuation.

- **Simulation Environment:** Tinkercad Circuits

- **Feedback / UI:** LCD 16x2 Display, Piezo Buzzer, Color-coded LEDs (Yellow, Orange, Red) 
- **Inputs:** Push Buttons (EQ simulation, Reset, Test), 10kΩ Potentiometer (Sensitivity adjustment)

## ⚙️ Core Architecture & Features

**Zero-Latency Interrupt-Driven Detection:** The system utilizes a hardware interrupt on Pin 2 (RISING edge) to ensure immediate detection of seismic activity. An Interrupt Service Routine (ISR) includes a 50ms debounce protection to prevent false counts generated by mechanical contact bounce.

**Intelligent Pulse Counting & Dynamic Classification:** Vibrations are analyzed over a fixed 5-second window. A potentiometer adjusts the detection sensitivity, allowing the system to dynamically recalculate the required thresholds for Moderate and Major earthquakes. 

**Non-Blocking FSM Architecture:** Operates on a 9-state finite state machine, progressing seamlessly from `STANDBY` to `EMERGENCY_ACTIVE` and `SYSTEM_RESETTING`. All core timing utilizes `millis()` comparisons to guarantee the microcontroller never freezes during multi-step actuator sequences, ensuring the system remains responsive to aftershocks.

**Graduated Automated Response:** - **Minor Quake:** Logs an informational alert with a Yellow LED and single beep.
- **Moderate Quake:** Issues a 10-second countdown warning via the LCD and an Orange LED.
- **Major Quake:** Activates a continuous siren (2000 Hz) and triggers critical safety procedures.

![QuakeGuard FSM Diagram](assets/fsm-diagram.png)

**Emergency Safety Protocols:** At t=0ms, the gas valve servo closes to 90°. Following this, at t=300ms, the emergency door lock servo opens to 180° to facilitate immediate building evacuation.

## 🎓 Engineering Takeaways

**Non-Blocking Operations Ensure Reliability:** Avoiding `delay()` function calls in state handlers is critical for an emergency system[cite: 153]. Ensuring that operations use `millis()` guarantees that the microcontroller can concurrently manage LCD updates, sirens, and servo positioning without experiencing system lockups.

**Pulse-Counting Over Duration:** Intelligent pulse-counting over a defined 5-second window heavily outperforms simple duration-based detection. This effectively filters out single bumps and false triggers while accurately identifying dangerous, sustained seismic frequencies.

**Fail-Safe Design:** Mechanical embedded systems must account for unpredictable constraints. Hardware and software debouncing prevents false positives, and the servos are designed to initialize into safe positions (gas open, doors locked) on restart or power loss.

## 🖥️ Usage Instructions

Because this project is fully simulated in Tinkercad, no local IDE installation or hardware is required.

### 1. Access the Simulation
Navigate to the provided Tinkercad link and click **"Copy and Tinker"** to load the project into your own workspace.

### 2. System Operation
- **Adjust Sensitivity:** Turn the blue potentiometer to set the detection sensitivity (0-100%) visible on the LCD.
- **Simulate Earthquake:** Rapidly click the "EQ" push button to simulate seismic vibrations. The system will aggregate the pulses over 5 seconds.
- **Test Mode:** Press the "Test" button to force a 30-pulse count, instantly guaranteeing a "Major Quake" response to demonstrate emergency protocols.
- **Manual Reset:** After an emergency response, press the "Reset" button to return actuators to their default safe positions and clear system flags.
